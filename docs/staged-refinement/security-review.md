# Итоговый обзор diff, данных и доступа

Это отдельный повторный анализ основным исполнителем и проверки инструментами. Он не называется независимым security-аудитом. Независимое визуальное ревью имеет свой явно ограниченный охват в independent-design-review.md. Production не проверялся.

| Область | Фактическое подтверждение | Граница |
| --- | --- | --- |
| Изоляция исходника | SHA-256 всех 274 файлов, тот же HEAD и porcelain status | Исходный Docker не служит доказательством свежести исходников |
| Секреты | local.env вне репозитория, 0600; в diff только .env.example с плейсхолдерами | Реальные интеграционные ключи не вводились |
| Логи | Новый сериализатор исключает query, headers и body; тест проверяет signed URL, токен и пароль; SMTP не печатает адрес/содержимое | Аудит по назначению содержит служебные ID и IP, доступен администратору |
| JWT/роли | Реальный гостевой и member-доступ к admin API отвергнут; editor не может верифицировать; unit-набор защищает привилегированные действия | Авторизация A использует Authorization, не ambient cookie. CORS не заменяет проверку JWT |
| Чужие записи | /me/orders фильтрует alumni_id; новый подтверждённый пользователь не получает чужие заявки; unit-проверки чужих ID | Синтетические аккаунты в отдельном Directus |
| Отзыв сессии | Реальный сброс пароля через Mailpit делает старый JWT недействительным; повторный токен отвергнут | Внешний SMTP не проверялся |
| Корзина/заказы | Реальная PG: одновременные повторы, последняя единица, rollback, однократный возврат резерва, запрет повторного открытия, блокировка отмены pending/paid | Обязательная новая переменная подключения и миграция; нет небезопасного fallback |
| Платежи | Серверные тесты webhook, сумм, повторов и выдачи подписки; pending фиксируется до запроса к провайдеру | ЮKassa без ключей: реальная оплата/возврат не проверены |
| Закрытое аудио | Directus Public возвращает 403; signed proxy отдаёт 206; просроченное право отзывает ранее выданную ссылку | Тестовый синтезированный звук. RuTube по внешней ссылке не является DRM |
| Подписка | Два одновременных HTTP-запроса сохранили одну заявку; право выдано реальным admin API | Успех заявки не активирует платное право сам |
| XSS/загрузка файлов | Существующие серверные проверки, белые списки форматов и экранирование React сохранены; полный unit/e2e прогон | Не проводился внешний penetration test; права на загружаемые материалы утверждаются владельцем |
| Rate limit | Реальные 429 при совмещённом интенсивном прогоне; лимиты не повышались для зелёного результата | Общий suite и matrix запускаются последовательно; NAT требует production-настройки по нагрузке |
| PWA | Установлен настоящий SW собранной версии; offline shell открывается; /api отсутствует в CacheStorage | Offline не подтверждает сохранение заявок; физический телефон и системный push отдельно |
| ДПО sync | Четыре регрессионных теста, повторный синк, сохранение ручного содержания/цен | На production не выполнялся |

Проверка миграции: CREATE TABLE IF NOT EXISTS выполнен повторно на alumni_staged, без удаления/изменения существующих пользовательских таблиц. План отката и складские условия в data-and-rollback.md. Не следует откатывать только API на старую схему резервирования, пока открытые резервы не сверены.
