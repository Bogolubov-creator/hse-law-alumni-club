## Дополнение: восстановление пароля

Интерфейс больше не показывает успешную отправку при ошибке запроса
`/auth/forgot`. Адрес сохраняется, доступны повтор и поддержка. Успешный ответ
остаётся одинаковым для существующего и неизвестного аккаунта. Реальную
доставку почты этот frontend-блок не проверяет.

## Дополнение: истёкшая сессия кабинета

Ответ 401 при загрузке профиля теперь возвращает ко входу с сообщением
«Сессия завершилась». Раздел из URL сохраняется: после повторного входа
пользователь продолжает работу с заявками. Обработка перенесена в проверку
доступа к кабинету, которая раньше перехватывала ошибку до нужного обработчика.
Временная ошибка сервера сохраняет сессию и допускает повторный запрос.

Проверка: ошибка 401 воспроизведена до изменения; браузерные сценарии
повторного входа и восстановления после 503 проверяются на подменённых
ответах API на desktop/mobile. Реальные учётные записи не используются.
Скриншоты нового состояния показываются пользователю перед пушем.
