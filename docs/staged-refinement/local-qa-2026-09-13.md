# Локальный стенд с базой · 13.09.2026

## Состав и изоляция

Compose-проект `alumni-local-qa`, файл `infra/compose.local-qa.yml`. Отдельные тома
PostgreSQL и загрузок Directus. Порты привязаны к 127.0.0.1:

| Сервис | Порт |
|---|---|
| Web, без VITE_MIRROR | 4290 |
| API | 3039 |
| Directus | 8059 |
| PostgreSQL | 55439 |
| Mailpit, интерфейс / SMTP | 8039 / 1039 |

Старые контейнеры и тома других стендов не изменяются. Секреты хранятся вне
репозитория, в файле с правами 0600. На текущем компьютере:
`~/.local/share/alumni-local-qa/runtime.env`. Копировать его в Git нельзя.
Mailpit принимает письма локально без SMTP relay; Telegram, YooKassa и push не настроены.

## Воспроизведение

1. Создать внешний env-файл со случайными POSTGRES_PASSWORD, DIRECTUS_SECRET,
   ADMIN_PASSWORD, DIRECTUS_SERVICE_TOKEN, AUTH_SECRET, ADMIN_AUTH_SECRET,
   TEST_EDITOR_PASSWORD, TEST_ALUMNI_PASSWORD. Задать синтетические адреса
   ADMIN_EMAIL, TEST_EDITOR_EMAIL, TEST_ALUMNI_EMAIL.
2. Выполнить `docker compose --env-file /absolute/path/to/runtime.env -f infra/compose.local-qa.yml up -d`.
3. Передать переменные файла в окружение процесса, добавить
   `DIRECTUS_URL=http://127.0.0.1:8059 SEED_DEMO=true` и запустить
   `pnpm --filter @club/scripts bootstrap`. Повторить последовательно для проверки идемпотентности.
4. Применить по порядку SQL из `apps/api/migrations/` к базе `alumni_qa`, с
   `psql -v ON_ERROR_STOP=1`. Пароль передавать через окружение, не аргумент CLI.
5. API: `API_HOST=127.0.0.1 API_PORT=3039`, DIRECTUS_URL и сервисный токен,
   CHECKOUT_DATABASE_URL к базе alumni_qa на 55439; SMTP_HOST=127.0.0.1,
   SMTP_PORT=1039, SMTP_FROM и OFFICE_EMAIL с тестовыми адресами,
   OFFICE_NOTIFY_CHANNEL=email, PUBLIC_URL=http://127.0.0.1:4290.
   Запуск `pnpm --filter @club/api dev` с изолированным окружением без внешних ключей.
6. Web: `VITE_MIRROR=false VITE_LOCAL_REVIEW=true API_PROXY_TARGET=http://127.0.0.1:3039 VITE_DIRECTUS_URL=http://127.0.0.1:8059 pnpm --filter @club/web dev --host 127.0.0.1 --port 4290`.

Локальные стартовые скрипты, журнал проверки и резервная копия находятся в
`~/.local/share/alumni-local-qa/`; они содержат только данные этого тестового стенда.

## Найдено и исправлено

- Лид программы `programs.tagline` был varchar(255), а источник содержит лид
  длиной 852 символа. Bootstrap падал при загрузке каталога. Поле создаётся как
  text; существующее расширяется через Directus без обрезания. Проверен фактический
  тип PostgreSQL после изменения, полный bootstrap и повторный bootstrap.
- API имел жёсткий bind на 0.0.0.0. Добавлен API_HOST с прежним значением по
  умолчанию; локальный стенд задаёт 127.0.0.1. Поведение Docker по умолчанию сохранено.

## Границы этапа

Это локальный стенд, не production. Все роли, конкурирующие покупки, весь CRUD
админки, реальные устройства и PWA ещё требуют отдельных проверок. Подкасты
на этом стенде пока не наполнены: зеркало имеет отдельные записи. Первое создание
заказа выполнено через API; клики корзины в браузере остаются следующим сценарием.
