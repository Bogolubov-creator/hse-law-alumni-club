# Поддержка, маскот и персональные данные

Состояние на 10.09.2026: поддержка и FAQ-бот работают на локальном стенде.
Оператор в коде зафиксирован (`packages/shared/src/operator.ts` – АНО «Клуб выпускников
факультета права НИУ ВШЭ», ОГРН 1257700005551). Полное соответствие production 152-ФЗ
всё ещё зависит от оргпакета (РКН, хостинг в РФ, внутренние документы) – см.
[152fz-compliance.md](../152fz-compliance.md).

## Работающая поддержка

Адрес: `/support` (канон V3; `/v2/support` редиректит). Обратная связь внутри сайта: тема, текст, отдельное согласие, код доступа, ответ администратора, дополнительные сообщения, закрытие и удаление обращения. Письма посетителям по тикетам не отправляются.

### FAQ-бот без ПД (ДПО + клуб)

Угловая ворона (SupportDock) открывает ClubSupportBot. Ответы – цитаты FAQ и каталог
программ. Тот же FAQ в Telegram при наличии токена. LLM нет. Gaps пишутся в
`club_faq_events` (без текста вопроса) и видны в админке Support (хиты за 30 дней).

## Запуск

Миграции поддержки и FAQ:

```sh
# club_support_tickets
psql "$CHECKOUT_DATABASE_URL" -f apps/api/migrations/20260908-support.sql
# club_faq_events + club_mail_outbox
psql "$CHECKOUT_DATABASE_URL" -f apps/api/migrations/20260910-ops-ttl-outbox-faq.sql
```

Переменные: `SUPPORT_ENABLED` (на проде `false`, пока оргпакет не готов),
`SUPPORT_OPERATOR_*` (по умолчанию из `CLUB_OPERATOR`), `SUPPORT_RETENTION_DAYS`.

## Что требуется для 152-ФЗ

| Область | Фактическое состояние | Что осталось |
| --- | --- | --- |
| Оператор и реквизиты | В коде и на `/privacy` / `/requisites` – АНО клуба, ОГРН 1257700005551 | Утвердить документы у органа управления; сверить полномочия |
| Цели и основания | Согласия форм + consent_version; поддержка – отдельное согласие | Разобрать основания по всем целям портала с юристом |
| Согласия форм | Чекбоксы пустые по умолчанию, серверная проверка | Согласовать редакции текстов с оператором |
| Локализация БД | Код готов к РФ-хостингу | Подтвердить VPS в РФ и offsite-бэкапы |
| Приём тикетов | `SUPPORT_ENABLED=false` на проде по умолчанию | Включить только после проверки оргпакета |
| Legal-баннер «проект» | Только при `VITE_LOCAL_REVIEW=true` | На прод-сборке флаг не ставить |

Стенс оплаты/push без секретов – [external-keys-checklist.md](../external-keys-checklist.md).
