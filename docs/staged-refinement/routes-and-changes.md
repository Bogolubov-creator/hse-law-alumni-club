# Карта возможностей и изменений

Исходные маршруты сохранены. Новый интерфейс доступен под /v2; основной адрес проверки http://localhost:5274/v2. Корневая / остаётся прежним интерфейсом для сравнения. Это локальный выпуск, выбор единственного production-маршрута потребует отдельного переключения и SEO-проверки.

| Маршруты | Было → стало | Сохранённый результат | Проверка |
| --- | --- | --- | --- |
| /, /v2 | Реестр на главной → самостоятельные афиша, новости, сценарные входы, история | CMS-блоки, все публикации и ссылки | public, staged-public, matrix, независимое визуальное ревью |
| /dpo, /v2/dpo | Один список → три фильтра, поиск, сортировка, закрытый набор, URL-сравнение до трёх | Цены в копейках, скидка подтверждённого участника только на ДПО, внешние программы ведут на HSE | staged-catalog, program-v2, orders/shared |
| /dpo/:slug, /v2/dpo/:slug | Сведения программы согласованы с API сравнения | Модули, преподаватели, документ, формат, старт, контакты и условия без обрезки | program-v2, staged-catalog, matrix |
| /merch, /v2/merch | Реестр → сетка/список с состоянием в URL | Категории, варианты, остатки и покупка | staged-merch, stress |
| /v2/merch/:slug | Новая адресуемая подробность по приёму Kimi | Те же данные и общий диалог выбора, reload и 404 | staged-merch, matrix |
| /events, /v2/events, /v2/events/:eventId | Календарь/список и быстрый просмотр + самостоятельный адрес события | Запись/отмена, .ics, баллы и напоминания | sections-v2, staged-public, API events |
| /news, /news/:slug, /v2/news, /v2/news/:slug | Сохранены slug и полный текст, на главной самостоятельная редакционная сетка | Прямые ссылки, canonical исходной страницы | sections-v2, public, matrix |
| /join, /v2/join; /lk, /v2/lk | Вход, регистрация и проверка офиса сохранены; формы защищены от fixed-панелей | Подтверждение почты, статус pending/verified, сессия | auth integration с Mailpit; join/lk e2e |
| /forgot, /reset и /v2/forgot, /v2/reset | Сохранено восстановление и отзыв старой сессии | Однократный токен из письма | auth integration, API auth |
| /cart, /v2/cart | Проверка склада → атомарный резерв, идемпотентная заявка | Гость/участник, смешанная корзина, самовывоз/доставка, контактные данные | real PG + staged-flow + cart-v2 |
| /v2/lk?section=overview/orders/community/achievements | Плоский кабинет → адресуемые разделы по приёму Kimi | Подробные заявки, друзья/интересы/активность, достижения, рефералы и баллы | lk-v2, matrix, реальное сохранение заявки |
| /lk/profile, /v2/lk/profile | Существующие настройки сохранены | Профиль, аватар, экспорт/анонимизация, Telegram, push | profile-v2; серверные тесты прав; matrix |
| /podcasts, /v2/podcasts | Общий плеер исправлен: позиция, ограниченное обновление ссылки, явная ошибка | Пробный/закрытый выпуск, скорость, подписка, RuTube | sections-v2; реальный локальный аудиопрокси/Range и проверка истечения права |
| /admin | Тематические разделы сохранены, адаптивность исправлена | Верификация, статусы, баллы, подписки, контент, аудит; ссылки Studio ведут в отдельный Directus | admin e2e, role tests, реальная смена статуса + reload, matrix |
| /privacy, /confidential, /requisites и /v2/* | Реквизиты переносятся на узком экране | Полные юридические страницы | public, matrix |
| /robots.txt, /sitemap.xml, manifest, sw.js | Dev/preview корректно проксируют SEO; PWA сохранена | Приватные страницы не индексируются, API не кэшируется | public, staged-runtime |

Сообщество существует внутри кабинета. Публичный каталог чужих контактов не добавлялся. Две исходные реализации сохранены для сравнения, но поддержка двух production-фронтендов не обещается.
