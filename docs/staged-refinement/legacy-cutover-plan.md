# План выключения `/legacy/*`

Канон UI уже на `/` (бывший v2). Прежний фронт живёт под `/legacy/*` в
`apps/web/src/App.tsx` – двойной UI и лишний бандл. Цель: убрать legacy без
поломки закладок и внешних ссылок.

## Зачем ещё держим

| Причина | Статус |
| --- | --- |
| Сравнение cutover / скриншоты | Исторические артефакты; e2e уже на каноне |
| Закладки и внешние ссылки на старые пути | Нужны редиректы, не две реализации |
| Страховка «откатить UI» | Git-тег / revert надёжнее, чем `/legacy` на проде |

## Этапы

### 1. Инвентаризация (сейчас)

- Маршруты: блок `<Route path="/legacy…">` в `App.tsx` (Home, news, dpo, merch, cart,
  podcasts, events, join/forgot/reset/confirm, lk, profile, legal).
- Сторож e2e: `join-legal-v2.spec.ts`, `sections-v2.spec.ts` – на каноне **нет** ссылок
  в `/legacy`.
- Lazy-импорты legacy-страниц всё ещё тянут код в chunk graph, пока маршруты есть.

### 2. Soft-cutover (1 релиз)

1. На каждый `/legacy/<path>` – `<Navigate replace to="/<path>" />` (или точный маппинг,
   если путь отличается).
2. Оставить код страниц ещё один релиз **или** сразу удалить импорты и оставить только
   редиректы (предпочтительно).
3. Прогнать e2e сторож + smoke: старые URL отдают 200/канон, не 404.
4. В sitemap / robots / внешних письмах – только канон (уже так).

### 3. Hard-remove (следующий релиз)

1. Удалить редиректы `/legacy/*` **или** оставить 301 на год в Caddy (лучше на прокси,
   чем React-роуты).
2. Удалить неиспользуемые `pages/*` legacy, если на них больше нет импортов.
3. Убрать упоминания «legacy UI» из handoff / acceptance; оставить ссылку сюда.

### 4. Критерии готовности

- [ ] Нет React-маршрутов, рендерящих старый UI
- [ ] Нет внутренних ссылок на `/legacy`
- [ ] Закладки `/legacy/…` ведут на канон (Navigate или Caddy)
- [ ] Bundle: нет orphan chunks старых Home/Dpo/Lk (проверить `pnpm -C apps/web build` +
  размер / rollup visualizer при сомнении)

## Не делать в этом проходе

- Не смешивать с redesign / MobileApp.
- Не трогать `/v2/*` редиректы отдельно (уже cutover); при hard-remove можно оставить
  их навсегда как дешёвые Navigate.
