# Аудио публичной витрины

Семь выпусков «Правовая грамотность» подключены к существующему EpisodePlayer
через `audio_url` в `apps/web/src/lib/mirror.ts`.

Файлы опубликованы отдельно от git в GitHub Release `podcast-audio-v1`:
https://github.com/Bogolubov-creator/hse-law-alumni-club/releases/tag/podcast-audio-v1

Версии для прослушивания: MP3, моно, 64 кбит/с; исходные записи сохранены.
Длительность всех семи версий сверена с оригиналами (отклонение меньше секунды).
Проверены HTTP 206 для диапазона в середине файла и декодирование звука с 60-й
секунды по публичной ссылке каждого выпуска. Тесты web и сборка прошли.

Запуск через встроенный браузер Codex завершился аварийным закрытием вкладки;
браузерное воспроизведение и перемотка требуют дополнительной проверки.

Эти адреса относятся к публичной витрине. Серверная выдача защищённых записей
через Directus и правила доступа API не изменялись. Все семь файлов в release
публичны, как и их прослушивание на витрине.
