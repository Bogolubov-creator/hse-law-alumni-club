# Источники и социальные достижения

В админке: Контент → Новости → Источники и обзоры. Обновление каждого источника,
общая очередь, фильтр, оригинал, свой анонс, черновик, редактирование и публикация.
Сайт и Mini App используют общую опубликованную ленту.

Сбор ограничен тремя адресами из NEWS_SOURCES. Произвольные URL не запрашиваются;
редиректы запрещены, объём и время ответа ограничены. В очереди сохраняются только
заголовок, дата, ссылка и источники. HTML и полный текст не публикуются.
Одинаковые URL объединяются, включая Telegram-репост со ссылкой на новость ВШЭ.
Разные публикации об одном событии без общей ссылки требуют редакторского выбора.
При изменении вёрстки источника ошибка видна в админке, сохранённые новости остаются.
Telegram: последняя доступная публичная страница, без обещания полного архива.

## Запуск сервера

Применить миграции штатным scripts/migrate.sh. NEWS_SYNC_ENABLED=true включает
сбор каждый час на 17-й минуте (Europe/Moscow). Ручное обновление доступно независимо
от флага. Включить переменную в окружении API и пересоздать контейнер.
На GitHub Pages нет API: кнопки обновления и импорта отключены, что явно указано.

Бот должен быть администратором @AlumniLawHSE для надёжного getChatMember.
Достижение «На радаре» отражает подтверждённую подписку при открытии кабинета,
с кэшем на 5 минут. Привязка Telegram берётся из проверенного серверного профиля.
«На волне»: 10 разных сообщений с активной персональной реакцией после привязки.
Задать TELEGRAM_REACTIONS_CHAT_ID для чата, где бот – администратор. Webhook настроить
scripts/setup-telegram-webhook.ts; allowed_updates включает message_reaction.
Polling также поддерживает эти события. Анонимные реакции, реакции ботов, чужой чат,
повторные и устаревшие события не увеличивают счётчик. Снятая реакция вычитается.
История реакций до подключения не восстанавливается. При удалении профиля данные очищаются.
Достижения не начисляют новые баллы: действующие правила баллов не меняются.
