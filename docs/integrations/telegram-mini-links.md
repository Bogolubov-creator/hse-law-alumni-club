# Прямые ссылки мини-приложения клуба

Ссылка предпросмотра: `/tg?startapp=dpo`. На зеркале перед `/tg` используется
базовый путь `/club-pravo-hse-mirror`.

После настройки Main Mini App у бота через BotFather можно использовать
`https://t.me/pravohse_alumni_bot?startapp=dpo`.
Само изменение фронтенда не настраивает Main Mini App и не запускает обработчик.

Поддерживаемые значения: `club`, `dpo`, `events`, `news`, `podcasts`, `merch`,
`stories`, `changes`, `saved`, `lk`, `support`. Для программы: `p_<slug>` – slug из каталога клуба, например
`p_business-mediation`. Это не числовой идентификатор из стороннего ДПО-приложения;
его формат кампаний `-c_…` здесь не применяется.

Приоритет: SDK `initDataUnsafe.start_param`, затем официальный URL-параметр
`tgWebAppStartParam`, затем `startapp` для предпросмотра. Параметр используется
только для навигации. Вход по-прежнему требует проверки подписанного `initData`
сервером. Внешние URL, путь админки и неизвестные команды игнорируются.

Переход выполняется один раз при запуске на главной или `/tg`. Если человек
уже открыл другой раздел, поздно загрузившийся SDK не меняет его выбор.
Несуществующая программа отображается штатной страницей отсутствующего товара.
Проверки браузера с имитацией SDK не заменяют приёмку внутри Telegram на телефоне.

Основание: [Telegram Mini Apps](https://core.telegram.org/bots/webapps) (проверено 23.10.2026).

## Бот и достижение за подписку

Бот проекта – [@pravohse_alumni_bot](https://t.me/pravohse_alumni_bot),
канал – [@AlumniLawHSE](https://t.me/AlumniLawHSE).

1. Участник подтверждает почту и проходит проверку учебного офиса.
2. В профиле нажимает «Подключить Telegram» и открывает одноразовую ссылку бота.
   Она действует десять минут. Команда `/start` связывает аккаунт с отправителем
   личного сообщения; указать чужой Telegram ID в форме проверки нельзя.
3. Участник подписывается на канал. При открытии кабинета сервер запрашивает
   `getChatMember`, используя привязанный ID; успешный результат хранится пять минут.
4. Кнопка «Проверить подписку» в профиле и достижениях запрашивает Telegram заново.
   Лимит – шесть запросов в минуту по правилам API. Повтор не создаёт вторую награду.
   Дополнительные баллы за эту награду не начисляются.

Для проверки других участников Telegram гарантирует работу `getChatMember`,
когда бот является администратором канала. [Требование Bot API](https://core.telegram.org/bots/api#getchatmember).
Не нужны права публикации сообщений для самого запроса проверки подписки.

На сервере секрет задаётся через `TELEGRAM_BOT_TOKEN`. Для приёма команд выбирают
один способ: `TELEGRAM_POLLING=true` при отсутствии webhook либо HTTPS webhook
`/api/telegram/webhook` с `TELEGRAM_WEBHOOK_SECRET`. Два обработчика одного бота
одновременно не запускают. При запуске production API с токеном и включённым планировщиком (`JOBS_ENABLED=true`) настраивает команды
и кнопку меню на `PUBLIC_URL/tg`; адрес должен вести к рабочему серверу.
Статическое зеркало не принимает команды и не проверяет подписчиков.

23 октября `getMe` подтвердил имя бота и включённый Main Mini App. Webhook отсутствует,
кнопка меню имеет тип `commands`. `getChat` нашёл канал, но `getChatMember` для самого
бота вернул `member list is inaccessible`. На локальном Ubuntu токен не задан.
По решению владельца подключение отложено. Эти проверки не подтверждают работу
бота с участниками или корректность сохранённого в BotFather адреса Mini App.

При выключенном токене интерфейс показывает, что проверка не подключена.
При ошибке Telegram награда не выдаётся по результату ошибки. Социальные достижения
сохраняются в `alumni_achievements`; просроченная проверка или результат для прежнего
Telegram ID не используются для новой выдачи.

## PWA и работа без сети

Манифест рабочего сайта запускает `/tg?source=pwa`; зеркало использует свой базовый
путь и каталог `/tg/`. На iPhone учитывается `navigator.standalone`. В установленном
приложении скрыты метка предпросмотра и предложение повторной установки.

До отключения сети нужно открыть сайт онлайн и дождаться установки service worker.
Мобильная главная и список сохранённого готовятся заранее. Ранее открытые публичные
страницы читаются до семи дней. Список ограничен 60 страницами; JavaScript, стили,
шрифты и синтетические справочники зеркала хранятся отдельно. Офлайн-копии отмечены датой.
Кабинет, админка, API, формы входа и корзина не попадают в кэш страниц.

В рабочем сайте разрешение на сохранение выдаёт сервер заголовком `X-Club-Offline`.
Для GitHub Pages экспорт формирует список допустимых публичных страниц. Этот список
и синтетические справочники отсутствуют в service worker обычной web-сборки.
Браузерная проверка standalone и офлайн-режима не заменяет установку на физический
iPhone или Android и запуск Mini App внутри Telegram.
