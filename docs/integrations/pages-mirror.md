# Статическое зеркало на GitHub Pages

Зеркало экспортируется из Jinja2-шаблонов без API и PostgreSQL. Публичные
разделы, демо-кабинет и панель офиса используют отдельные фикстуры.
Регистрация, отправка заявки и сохранение серверных правок отключены.

Репозиторий: [club-pravo-hse-mirror](https://github.com/Bogolubov-creator/club-pravo-hse-mirror).
Адрес: [Pages-зеркало](https://bogolubov-creator.github.io/club-pravo-hse-mirror/).
Текущий исходный коммит записывается в `version.json` при публикации.

## Локальная сборка

Из корня проекта:

```bash
uv sync --directory frontend --frozen
uv run --directory frontend python -m club_web.mirror --output /tmp/club-mirror --base /
uv run --directory frontend python -m http.server 4173 --bind 127.0.0.1 --directory /tmp/club-mirror
```

Откройте `http://127.0.0.1:4173/`. Для GitHub Pages укажите базовый путь
`--base /club-pravo-hse-mirror/`. Экспортёр создаёт HTML каждой страницы,
`404.html`, фрагменты, manifest, `.nojekyll`, статические данные и календарные файлы.

## Поведение

- Демо-кабинет и офис показывают синтетические данные. Доступ к ним не является
  серверной авторизацией.
- Корзина хранится в `sessionStorage` вкладки; можно добавить, изменить и удалить
  позиции. Отправка заявки отключена.
- Поиск, фильтры каталога и дайджеста, сравнение и календарь работают локально.
- Сохранённые материалы используют хранилище браузера.
- PWA и Telegram-предпросмотр используют тот же интерфейс; для PWA есть `?pwa=1`.
- Семь подкастов подключены к ранее опубликованным публичным MP3. Деморежим
  подписчика обозначен явно: [поведение аудио](podcast-mirror-audio.md).
- Страницы имеют `noindex`. Данные и помощники зеркала не входят в рабочий web-образ.

## Обновление

Workflow в репозитории зеркала получает выбранный `source_ref`, устанавливает
Python-зависимости по lockfile, обновляет дайджест и запускает экспортёр.
Затем публикуется каталог HTML и статики. Проверяют результат workflow,
`version.json`, ссылки и пользовательские сценарии опубликованного сайта.

Импорт дайджеста описан в [LegisDigest](legis-digest-integration.md).
Проверка настоящих сервисов выполняется по [runbook](../operations/deploy-runbook.md).
