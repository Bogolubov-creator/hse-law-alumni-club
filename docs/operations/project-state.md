## Организация каталогов

По дополнительному поручению владельца код разложен по предметным областям:
`backend/club_api/modules`, общий SQL-слой `db`, конфигурация, общие механизмы,
расписание и наблюдение. В интерфейсе выделены `features`, `api`, `hooks`,
`stores` и `layouts`. Тесты всех пакетов находятся вне `src`.
Docker-файлы и конфигурация Caddy собраны в `deploy`, SQL – в `backend/sql`.
Помощники операций, проверки и диагностика отделены от команд оператора.
Документация разложена по назначению. Карта – в
[структуре проекта](../development/repository-structure.md).

При переносе обновлены импорты, обнаружение тестов, Docker/Compose, CI,
операционные пути и ссылки. Маршруты, роли, цены, расчёты и порядок миграций
сохранены. Старая копия может использовать прежний путь к SQL-правам runtime;
restore учитывает оба расположения. Установка зависимостей не меняет lockfile.
Локальная проверка включает сборку, lint, unit, SQL и проверки операций.
CSS-файлы совпали с исходной сборкой. Новый CI сверяется с SHA самого PR;
предыдущий успешный CI не используется как результат проверки переноса.
