# Спека для разработки: публичный контур v2

Контракт между дизайном и кодом. Токены и правила системы – в
[design-system.md](./design-system.md), решения и их обоснование – в
[DESIGN.md](../DESIGN.md). Здесь только то, что нужно, чтобы собрать экран и не
угадывать.

**Стек:** React 18 + Vite, React Router 7, TanStack Query, CSS-переменные
(не Tailwind – он остался в v1), инлайновые стили из `styles/primitives.ts`.

---

## 1. Сетка и брейкпоинты

Полоса набора – `var(--container)` = 1180px, поля 28px, центрирование
`margin: 0 auto`.

| Брейкпоинт | Что меняется |
|---|---|
| ≥ 900px | десктоп: герой в две колонки `1.15fr 0.85fr`, горизонтальная навигация в шапке, вкладок снизу нет |
| < 900px | герой в одну колонку, иллюстрация уходит наверх (`order: -1`, до 132px), навигация сворачивается в меню |
| < 768px | v1 подменяется мобильной оболочкой `MobileApp`; **v2 этого не делает** – у него своя адаптация |
| < 620px | телефон: иллюстрация героя 76px, шапка героя `padding-top: 16px`, строки реестра `68px 1fr` |

**Долг:** в `index.css` восемь разных `max-width` – 620, 760, 768, 860, 900,
920, 1000, 1024. Канон – **620 / 768 / 900**; остальные (760, 860, 920, 1000,
1024) остались от v1 и нормализации ещё не прошли. Новый код берёт только
канонические.

Дополнительные условия среды:

| Условие | Действие |
|---|---|
| `(pointer: coarse)` | `.tap` вырастает до 44px – тач-цель под палец |
| `(hover: hover)` | ховер-эффекты карточек; на таче не применяются |
| `(prefers-reduced-motion: reduce)` | все анимации и переходы выключаются глобально |
| `(display-mode: standalone)` | PWA: снимается резиновый скролл |
| `env(safe-area-inset-*)` | отступы шапки, подвала и нижних вкладок |

## 3. Компоненты и пропсы

### Оболочки

| Компонент | Пропсы | Что даёт |
|---|---|---|
| `V2Shell` | `children` | ссылка-пропуск, шапка с навигацией и темой, подвал, `--tabs-h`/`--cookie-h` в отступах |
| `CabinetShell` | `active: "lk" \| "profile"`, `onLogout: () => void`, `children` | приватная зона: боковая навигация, выход |
| `AuthShell` (внутри `JoinAuthV2`) | `title`, `sub?`, `children` | экраны входа; `<main id="main">`, юр-ссылки под карточкой |

Каждая оболочка обязана дать ровно один `<main id="main">` – на него ведёт
ссылка-пропуск.

### Витринные примитивы

| Компонент | Пропсы | Примечания |
|---|---|---|
| `ShowcaseHead` | `eyebrow: string`, `title: string`, `lead: string`, `count?: string` | ровно один `h1` на страницу; `count` включает `BlankField` |
| `BlankField` | `label: string`, `children` | **только там, где под линией настоящие данные реестра** |
| `Mark` | `kind?: "scales" \| "themis"`, `size?: number \| string`, `title?`, `style?`, `className?` | `title` задавать, только если знак несёт смысл сам |
| `Lockup` | `size?: number`, `mono: CSSProperties`, `disp: CSSProperties` | локап шапки: знак + имя клуба в две строки |
| `MobileTabs` | – | 5 вкладок, бейдж корзины, `aria-current="page"` |

### Примитивы кабинета

| Компонент | Пропсы |
|---|---|
| `DataRow` | `name: string`, `value: string`, `accent?: boolean` |
| `Section` | `title: string`, `note?: string`, `children` |
| `Initial` | `fio: string \| null \| undefined`, `size: number`, `radius: string` |
| `Progress` | `value: number`, `target: number`, `done: boolean` |

### Общие

| Компонент | Пропсы | Поведение |
|---|---|---|

## 4. Состояния

### Действие (`action` / `actionGhost`)

| Состояние | Вид | Как включается |
|---|---|---|
| обычное | охра, тёмный текст 5,12:1 | – |
| фокус | обводка 3px `--c-accent`, отступ 2px | `className="foc"` **обязателен** |
| наведение | у кнопок нет; у ссылок навигации – `--c-accent-text` | `.nav-link`, `.shop-nav` |
| недоступно | прозрачность 0,45, курсор `not-allowed` | атрибут `disabled` – правило глобальное |
| занято | `disabled` на время запроса | текст кнопки **не меняется** |
| тач-цель | ≥44px на сенсорном вводе | `className="foc tap"` |

### Форма

| Элемент | Состояние | Поведение |
|---|---|---|
| поле | обычное | `field`, контур `--c-line-control` |
| поле | фокус | `.foc` |
| поле | обязательное | `required`; звёздочку не рисуем |
| форма | ошибка | `<p role="alert">` под формой, цвет `--c-danger-text` |
| форма | отправка | кнопка `disabled`, ярлык «Отправляем…» |

**Долг:** ошибка не связана с полем (`aria-invalid` + `aria-describedby`
отсутствуют). Критерий 3.3.1, уровень A – закрыть до релиза.

### Загрузка и пустота

| Ситуация | Что показывать |
|---|---|
| загрузка списка | счётчик в `ShowcaseHead` переходит в «загружаем каталог»; спиннер не нужен |
| пусто по фильтру | что не нашлось + кнопка, снимающая фильтр |
| пусто вообще | что это за раздел + кто наполняет + куда пойти вместо |
| не найдено (404) | заголовок «… не найдена» + `noindex` + ссылка на список |

Пустое состояние без действия – ошибка спеки. Формулировка не должна обещать
того, чем никто не управляет («скоро появятся»).

## 5. Голос интерфейса

Заявку обрабатывает учебный офис. Онлайн-оплата подключается ключами ЮKassa;
пока их нет, кнопка оплаты просто не отображается.

| Можно | Нельзя |
|---|---|
| «Оформить заявку» | «Купить», «Записаться», «Оплатить» до подтверждения |
| «Учебный офис подтвердит детали и пришлёт ссылку на оплату» | «Запись пройдёт автоматически» |
| «Цена выпускника действует, когда учебный офис подтвердит ваш выпуск» | «Скидка применится автоматически после верификации» |
| «Заявка в работе у учебного офиса» | «Учебный офис получил заявку» – уведомление может не дойти, и страница сама об этом пишет |
| «О новых напишем в новостях клуба» | «Скоро появятся» |

Слово **«верификация»** – из админки. Выпускнику говорим «подтвердит выпуск».
Действующее лицо – **«учебный офис»**, не «менеджер» и не «мы».

## 6. Крайние случаи

- **Длинные строки из источника.** Названия направлений ДПО приходят с hse.ru
  сырыми, до 90 знаков. Чип не обрезается и переносится – верстать под перенос.
- **Двадцать один пункт каталога.** Списки не виртуализируются; при росте
  каталога вдвое понадобится пагинация.
- **Отсутствие картинки товара.** Плашка «БЕЗ ФОТО» 96×72, `--t-micro`.
- **Уведомление офиса не прошло.** Заявка сохранена; страница обязана это
  сказать и дать телеграм-канал, а не молчать.
- **Истёкшая сессия.** Токен снимается, навигации нет: гость на публичной
  странице остаётся на месте, защищённые экраны сами показывают вход.
- **Подписанная ссылка на аудио протухла.** Плеер сообщает `role="alert"` и
  предлагает обновить.

## 7. Движение

`MOTION_INTENSITY` внешнего контура – 4: один оркестрованный момент на входе,
остальное – состояния.

| Элемент | Триггер | Что | Длительность | Кривая |
|---|---|---|---|---|
| Герой главной | загрузка | подъём на 14px + проявление, каскад 40/60/120/180ms | 300ms | `--ease-out` |
| Карточка витрины | наведение (только `hover: hover`) | подъём 2px, контур в охру | `--dur-base` | `--ease-out` |
| Чип фильтра | клик | смена заливки и контура | `--dur-fast` | `--ease-out` |
| Ссылка-пропуск | фокус | выезд сверху `-60px → 12px` | `--dur-fast` | `--ease-out` |
| Полоса прогресса | смена значения | ширина | 1s | `cubic-bezier(.4,0,.2,1)` |

Анимируются только `transform` и `opacity`. При
`prefers-reduced-motion: reduce` всё выключается одним правилом
`[class] { animation: none !important; transition: none !important; }`.

## 8. Доступность: контракт экрана

- **Один `h1`.** Уровни заголовков не перепрыгиваются.
- **`<main id="main">`** ровно один; ссылка-пропуск первой остановкой табуляции.
- **`className="foc"`** на каждом интерактивном элементе; `tap` – там, где палец.
- **Контур элемента управления** – `--c-line-control`, не `--c-line`.
- **Текст мельче 12px не набирается.**
- **Заливочный тон не ставится как цвет текста** – для текста есть `-text`.
- **Версия для слабовидящих доступна с любой ширины экрана.**
- **Слои с собственным фоном** (`[role="dialog"]`, `.vis-bar`, `header`)
  исключены из сброса версии для слабовидящих – иначе их текст ложится поверх
  страницы.
- **`alt` у картинки обязателен**, пустой для декоративной.

Проверяется автоматически: [`design-language.spec.ts`](../apps/web/e2e/design-language.spec.ts)
и [`a11y.spec.ts`](../apps/web/e2e/a11y.spec.ts).

## 9. Чего в спеке намеренно нет

- **Админка.** Плотный инструмент офиса, живёт по своим правилам
  (`admin/ui.tsx`), витринный язык туда не распространяется.
- **v1 и мобильная оболочка.** Не имеют токенов и держат свою палитру
  (`lib/lk-theme.ts`). Если релизится v1 – ему нужна отдельная спека.
- **Кнопка как компонент.** Её не существует: 19 инлайновых сборок с девятью
  паддингами. До вынесения в компонент новый код берёт `action` / `actionGhost`
  из `primitives.ts`, а не собирает кнопку заново.
