## Ubuntu

Проверена новая Lima/VZ VM без монтирования каталогов Mac: 4 vCPU, 6 GiB RAM,
20 GiB диск, ARM64. Установка начата на Ubuntu 24.04.4; системные обновления
довели её до 24.04.5 и ядра `6.8.0-142-generic`. После обновления выполнен настоящий
`reboot`: boot ID изменился, Docker и оба таймера запустились самостоятельно.
Docker 29.8.1, Compose 5.5.1, Buildx 0.37.1 установлены внутри VM.

В legacy-источнике пять пользователей, три профиля, одна страница; файлов, заявок,
программ и товаров было 0. Сверены UUID/пароли/роли, выбранные поля профиля, записи
файлов, полные настройки и счётчики. Исходная VM после переноса сохранила те же
fingerprints. Проверку байтов существовавших legacy-файлов нельзя заявить при
нулевом их количестве. Exact restore отдельно проверил настоящий PNG и три WAV.

В реальной репетиции выявлены и исправлены: повторный bootstrap через Compose
start, недоступный для `docker run` config digest в Docker 29, неподдерживаемый
`create --no-deps`, слишком раннее завершение standalone backup до healthy API.
Неудачный первый restore не затронул исходный проект; повтор выполнен заново.
Для legacy snapshot закреплён инструмент `17053fad1b61f7408cc21788035b3b52c5da94d4`;
нативные исправления входят в `110008d`.

HTTPS source: `https://localhost:9445`, Mailpit: `http://localhost:9126`. API/PG
порты хоста не имеют. Валидация сертификата выполнялась по CA без `-k`.
Локальные сертификаты Caddy действуют около 12 часов; порог QA-monitor 0,25 дня
отличается от публичного 14 дней. Внешний канал не настроен: отчёт остаётся в
journald и `last-monitor.json`. Offsite не настроен и не заявлен.

Предел нагрузки, минимальная аппаратная конфигурация и рабочий объём данных
не измерены. Результаты, размеры и допущения – в [capacity.md](capacity.md).

## Условия публичного выпуска

Нужны рассмотрение и последовательное объединение PR владельцем, согласованные
VPS/домен, SMTP с проверенной доставкой, offsite с проверкой чтения, ответственный
и канал оповещений. При включении интеграций нужны проверки платёжного магазина,
Telegram и push. Права на контент/шрифты и реквизиты подтверждает владелец.
Локальная репетиция не подтверждает работу этих внешних компонентов.
