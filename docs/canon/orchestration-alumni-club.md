## 1. Дизайн-направление (поднятое по качеству)

### Концепция
«Право как конструкция»: фасеточная Фемида из вашей картинки – это не просто логотип, а **собирающийся из осколков** при загрузке объект, который потом живёт параллаксом по странице. Оранжевый – энергия клуба, синий ВШЭ – институциональный якорь, латунь – «премиальность» статуса.

### Палитра (токены)
```
--ohra            #EC5A13   /* основной акцент, CTA, хайлайты */
--ohra-deep       #C9450E   /* hover, тени акцента */
--karmin          #B5331B   /* «тёплая» фасетка, предупреждения уровня */
--hse-blue        #11296B   /* институциональный синий ВШЭ, тёмные секции */
--blue-br         #2E6FAE   /* «холодная» фасетка, ссылки на тёмном */
--stal            #2C6E80   /* вторичный холодный */
--latun           #C49A45   /* статус, премиум, медали */
--latun-br        #E3C272
--grafit          #14181F   /* текст, тёмный фон */
--kost            #FBF3E8   /* тёплый светлый фон */
--kost-2          #F2E3CF   /* карточки/секции */
/* нейтрали UI: #6B7280 серый текст, #E5E7EB бордеры */
```
Светлая тема – для публичного сайта и витрин; тёмная (графит/ВШЭ-синий) – для секций «история», футера и ЛК-хедера. Поддержать и dark-mode для ЛК.

### Типографика
- **Display:** `Unbounded` (600/800) – заголовки, цифры, фирменный знак. Кириллица, российская студия, узнаваемость. Используем дозированно.
- **Body:** `Onest` (400/500/600) – основной текст, UI. Чистый современный гротеск с отличной кириллицей.
- **Mono/данные:** `Martian Mono` или `JetBrains Mono` – цены, баллы, таблицы заказов.
- Тип-шкала: 12 / 14 / 16 / 20 / 28 / 40 / 64 (clamp на мобиле). Межбуквенный для display: −0.01em.

### Сетка и форма
- Контейнер 1200px, 12 колонок, gutter 24px. Радиусы 12/18px. Тени мягкие, низкие.
- Сигнатурные разделители секций – тонкая «фасеточная лента» из 5 цветов палитры.

### Motion и скролл-эффекты (то, что вы просили)
Базис: `Lenis` (плавный скролл) + `GSAP ScrollTrigger` (или Framer Motion `useScroll`).
- **Hero:** Фемида собирается из 12–16 осколков (stagger 40мс) при загрузке; дальше – параллакс (осколки чуть расходятся при скролле).
- **Reveal:** секции и карточки появляются маской снизу-вверх (clip-path / y-fade), порогом 15%.
- **История клуба:** горизонтальный скролл-таймлайн (pinned), годы ’24 → ’25 → …, шаги с фото и метриками.
- **Счётчики:** count-up для «выпускников / программ / городов» при попадании в вьюпорт.
- **Витрины:** sticky-фильтры слева, карточки товара с hover-tilt и быстрым просмотром.
- **Кнопки:** «магнитный» hover у основных CTA; на нажатии – лёгкий squash.
- **Маркизы:** бегущая строка логотипов выпусков/партнёров.
- **Обязательно:** полный `prefers-reduced-motion` фоллбэк (всё мгновенно, без параллакса), видимый focus-ring, доступность с клавиатуры.

### Компоненты-сигнатуры
1. Фасеточный знак Фемиды (SVG, переиспользуется как фавикон, маркер секций, лоадер).
2. «Карта уровня» – профиль с кольцом прогресса и фасеточной заливкой по уровню.
3. Карточка товара/программы с бейджем персональной скидки.

## 3. Модули и спеки (кратко, для промтов)

**3.1 Публичный сайт + история.** Блочные секции, редактируемые из CMS. История – таймлайн по выпускам.
**3.2 Новости.** Лента + страница поста; авто-импорт превью из Telegram-канала @pravohse (опционально, фаза 5).
**3.3 ЛК + профиль + достижения.** Профиль: ФИО, выпуск, статус верификации, уровень, баллы, бейджи. Достижения: «Первый шаг», «Нетворкер», «Знаток» (3 программы), «Наставник», «Легенда выпуска».
**3.4 Геймификация.** Уровни: Выпускник 5% (0) → Друг клуба 10% (200) → Знаток 15% (500) → Амбассадор 20% (1000). Баллы за программы (+100), события (+60), рефералов (+80), менторство (+120). **Decay:** ежемесячно −X% за неактивность → возможно понижение уровня («просел»). Источник правды – реестр транзакций баллов (points ledger).
**3.5 Витрина ДПО.** Каталог программ: фильтры (направление, формат, длительность), карточка с датами/ценой/программой, цена с учётом скидки выпускника.
**3.6 Витрина мерча.** Каталог товаров: категории, варианты (размер/цвет), остатки, галерея.
**3.7 Корзина и заказ (общая).** Единая корзина, но позиции из двух витрин помечены типом. Checkout: контакты, доставка (для мерча), применение членской скидки, оплата ЮKassa, статусы заказа, письмо-подтверждение.
**3.8 Админ/CMS.** Блочный редактор страниц, CRUD контента, заказы, верификация, начисление баллов/скидок, правила достижений.
**3.9 Mini-app.** Тот же фронт в обёртке Telegram Mini App и «Макс» mini-app; вход через Telegram/Госуслуги-«Макс»; шаринг и рефералка; пуши.

## 4. Техническая архитектура (рекомендация)

**Принцип:** не строить CMS и админку с нуля – взять headless-CMS как «бэкенд правды» и админку, а кастомной логикой закрыть только геймификацию, корзину/заказы и оплату. Это экономит месяцы.

```
┌─────────────────────────────────────────────┐
│  Frontend (Vite + React + TS + Tailwind)      │
│  Framer Motion / GSAP + Lenis (скролл)        │
│  TanStack Query + Zustand · shadcn/ui         │
│  Сборка: web + Telegram Mini App + Макс       │
└───────────────┬───────────────────────────────┘
                │ REST/GraphQL
┌───────────────┴──────────────┐   ┌──────────────────────────┐
│  Directus (CMS + Admin + Auth)│   │  Кастомный API (Fastify/  │
│  pages, news, alumni,         │   │  NestJS, TS):             │
│  programs, products, ledger,  │←→ │  cart, checkout, orders,  │
│  achievements, roles/perms    │   │  gamification engine,     │
└───────────────┬──────────────┘   │  decay cron, payments     │
                │                    └─────────────┬────────────┘
        ┌───────┴────────┐                         │
        │  PostgreSQL     │                ┌────────┴────────┐
        └────────────────┘                 │ ЮKassa (оплата) │
   Хостинг: ваш VPS, Docker Compose         └─────────────────┘
   (directus + postgres + api + caddy/nginx + frontend)
```

**Почему так:**
- **Directus** даёт готовую админку (редактирование страниц/новостей/товаров), роли/права, авторизацию и API из коробки – закрывает §3.8 почти целиком.
- **Кастомный API на TS** (ваш стек) – только то, чего нет в CMS: корзина, заказы, платежи, движок баллов и cron-decay.
- **Альтернатива для коммерции:** если ассортимент вырастет – вынести витрины в `Medusa.js` (headless-commerce на TS). На старте достаточно коллекций Directus + лёгкого checkout.
- **Оплата:** ЮKassa (карты, СБП). Карточные данные – на стороне провайдера (мы их не трогаем).
- **Деплой:** Docker Compose на вашем VPS, Caddy для авто-TLS.

### Схема данных (ключевые коллекции)
```
alumni(id, user_id, fio, cohort, status, verification_status,
       points_cached, level_cached, personal_discount, joined_at)
points_ledger(id, alumni_id, delta, reason, ref, created_at)   // источник правды
achievements(id, key, title, rule_json)
alumni_achievements(alumni_id, achievement_id, earned_at)
pages(id, slug, blocks_json, status)
news(id, slug, title, cover, body, published_at)
programs(id, slug, title, direction, format, duration, price, dates, capacity)   // ДПО
products(id, slug, title, category, price, images, variants_json, stock)         // мерч
carts(id, alumni_id|session, items_json, updated_at)
orders(id, alumni_id, type[mixed], items_json, subtotal, discount, total,
       status, payment_status, shipping_json, created_at)
offers(id, alumni_id|level, percent, kind[level|personal], active)
```
