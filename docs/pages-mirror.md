# Статическое зеркало на GitHub Pages

Зеркало – отдельная сборка интерфейса без API и PostgreSQL. Оно позволяет
посмотреть публичные разделы, демо-кабинет и панель офиса с синтетическими
данными. Регистрация, отправка заявки и сохранение правок через сервер в нём
недоступны.

Репозиторий выкладки:
[Bogolubov-creator/club-pravo-hse-mirror](https://github.com/Bogolubov-creator/club-pravo-hse-mirror).
Адрес, заданный командой сборки:
[Pages-зеркало](https://bogolubov-creator.github.io/club-pravo-hse-mirror/).
Эта инструкция не подтверждает текущую внешнюю публикацию или её версию.

## Локальная сборка

Из корня монорепозитория:

```bash
pnpm --filter @club/web build:mirror
pnpm --filter @club/web preview:mirror
```

Откройте `http://127.0.0.1:4173/club-pravo-hse-mirror/`. Команда задаёт
`VITE_MIRROR=true`, `VITE_BASE=/club-pravo-hse-mirror/` и публичный
`VITE_SITE_URL`, затем создаёт `404.html` для переходов SPA и `.nojekyll`.
Флаги зеркала не передавайте обычной Docker-сборке сайта. Проверка содержимого
сборки описана в [testing.md](testing.md).

## Поведение

- Демо-кабинет и панель офиса используют фикстуры и демонстрационные сессии;
  они не подтверждают серверную авторизацию или сохранение данных.
- Корзина хранится в `sessionStorage` текущей вкладки и переживает перезагрузку.
  Отправка заявки отключена. Недоступная серверная операция не должна показывать
  успешное сохранение.
- Мобильная оболочка использует тот же интерфейс. Для локального предпросмотра
  доступна `pnpm --filter @club/web preview:mobile` и параметр `?pwa=1`.
- Подкасты используют отдельные публичные аудиоссылки и обозначенный деморежим:
  [поведение аудио](podcast-mirror-audio.md).
- Страницы зеркала предназначены для демонстрации и имеют `noindex`.

## Обновление

Внешний workflow находится в репозитории зеркала; перед публикацией проверьте
его выбранный `source_ref`, конфигурацию Pages и результат для конкретного SHA.
Настройка и запуск этого workflow не входят в локальную сборку Клуба.
Правила импорта материалов `/changes` описаны в
[интеграции LegisDigest](legis-digest-integration.md).

Демо-токены, фикстуры, публичные аудиоссылки и копия витрины не подтверждают
работу SMTP, оплату, выдачу защищённых файлов или состояние публичного сервера.
Для проверки приложения используйте настоящий стек по [runbook](deploy-runbook.md).
