# Components

Shared primitives live in `apps/web/src/v2/` and `apps/web/src/components/`.

## Mark (`apps/web/src/v2/Mark.tsx`)
Inline SVG scales / themis on `currentColor`.

## BlankField (`apps/web/src/v2/Shell.tsx`)
`.blank-field` line + mono caption – registry signature.

## V2Shell
Sticky header with Mark + nav (ДПО, Мерч, Подкасты, События, Новости), cart, theme toggle, footer.

No shadcn/MUI – custom CSS tokens.
